# Keep Spend Insight Facts Deterministic

Spend Style, Financial Pace, guided exploration, and exact chat answers are calculated from local
ledger data by server modules; AI may only write bounded summaries, classify a natural-language
question into a validated intent, or word subjective advice from supplied facts. This trades some
prompt flexibility for stable results, auditable arithmetic, correct ledger/scope handling, and the
ability to change providers without changing a user's financial classifications.
